# to-do-list
aplikasi to do list berbasis terminal dengan python

## Fitur
- Menampilkan daftar tugas
- Menambahkan tugas
- Menghapus tugas yang telah selesai
- Penyimpanan otomatis ke dalam file tugas.txt

## Konsep Python yang digunakan
Fungsi, list, pengulangan, percabangan, membaca/menulis file, serta penanganan kesalahan dengan try/except

## Cara menjalankan
1. Pastikan Python telah diinstal
2. Eksekusi python to_do_list.py di terminal
3. Pilih opsi berdasarkan nomor yang muncul

## Catatan
Proyek ini dibuat sebagai latihan dasar dalam pemrograman Python
